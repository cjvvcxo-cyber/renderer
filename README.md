# CxO Direct MP4 Renderer

This renderer uses WebCodecs `VideoEncoder` with H.264 and `mp4-muxer` to create an MP4 directly in the browser. It does not use MediaRecorder, real-time canvas capture, WebM, or FFmpeg conversion.

## Deploy

Upload `index.html`, `styles.css`, `app.js`, and `README.md` to the root of the GitHub repository. Use GitHub Pages over HTTPS.

## Use

1. Choose the project JSON.
2. Choose the image folder.
3. Optionally choose the logo.
4. Confirm Missing = 0 and H.264 = Ready.
5. Preview the first scene.
6. Click Render MP4.
7. Keep the page open until the MP4 downloads.
8. If automatic download is blocked, click Download MP4 again.
